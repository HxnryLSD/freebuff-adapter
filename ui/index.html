RUNNING SAFELY

Windows SmartScreen warning

This app ships unsigned (code-signing certificates that Windows trusts cost money, so the project deliberately doesn't buy one). Windows will show "Windows protected your PC" / "Unknown publisher" the first time you run the installer or the portable exe. That warning is expected for this app — but verify before you dismiss it:

  • You downloaded the file from this project's GitHub Releases page the version tag you intended, not from an email, chat link, or search ad.
  • The filename matches that release (e.g. Freebuff Adapter Setup x.y.z.exe).
  • You are on the machine that will actually use it.

Then dismiss it safely:

  • On the dialog: click More info → Run anyway.
  • Or in Explorer: right-click the file → Properties → tick Unblock → OK.

Why it's unsigned

Trusted code-signing certs are paid (a CA cert or a cloud signing subscription). Free alternatives either aren't trusted by Windows (self-signed) or require project approval (SignPath's free OSS tier). So the app ships unsigned by design; the daemon itself has zero runtime dependencies and runs fine from node src/index.js if you prefer to skip the installer entirely.

Security defaults

  • The daemon binds to 127.0.0.1 only — nothing is exposed to the network.
  • Your token is stored in ~/.config/freebuff-adapter/state.json (mode 0600).
  • Set FREEBUFF_PROXY_KEY before binding to anything but loopback; the local UI is always exempt.

FREEBUFF DEVICE-CODE LOGIN

The daemon will request a login code from freebuff.com, open your browser, and poll until you sign in. You can also paste the URL manually.
